Программа для macOS, которая раскладывает окна и не делает ничего, кроме деления экрана.

*Waridake* (割り竹) — «расколотый бамбук»: один чистый разрез, и всё.

**Что она делает:**

1. Вы задаёте зоны для каждого монитора
2. Удерживайте **Shift во время перетаскивания окна** — появятся зоны
3. Отпустите над зоной, и окно встанет в неё

Никаких сеток горячих клавиш, никакой истории окон, никаких подписок. Живёт в
строке меню.

> Первоисточник — английский [README.md](README.md). Если этот перевод отстал,
> верен английский.

## Установка

Нужны инструменты командной строки Xcode (`xcode-select --install`).

```bash
git clone https://github.com/omikuji/waridake.git
cd waridake
make install   # → /Applications/Waridake.app
```

При первом запуске macOS попросит разрешение на универсальный доступ. Включите
Waridake в **Системных настройках → Конфиденциальность и безопасность →
Универсальный доступ**. Достаточно сделать это при запущенной программе: она
заметит в течение секунды, перезапуск не нужен.

Чтобы запускалась при входе: Системные настройки → Основные → Объекты входа.

### О пересборке

По умолчанию подпись ad-hoc, поэтому **при каждой сборке она меняется, и macOS
молча отзывает разрешение** — галочка на месте, но ничего не работает. Уберите
Waridake из списка и добавьте заново либо решите вопрос окончательно: создайте
самоподписанный сертификат для подписи кода (Связка ключей → Ассистент
сертификации → Создать сертификат, тип: подпись кода) и собирайте с ним:

```bash
make install SIGN_IDENTITY="Waridake Dev"
```

## Как пользоваться

Всё находится под значком в строке меню.

| Пункт меню | Что делает |
| --- | --- |
| **Разложить открытые окна** | Ставит каждое открытое окно в ближайшую зону. Чтобы прибраться, когда окна разъехались |
| **Изменить макет…** | Визуальный редактор, описан ниже |
| **Макеты…** | Макеты по мониторам с датой последнего использования и история правок |
| **Изменить как JSON…** | Файл настроек в простом окне редактирования |
| **Перезагрузить макет** | Перечитывает файл после правки в другом редакторе |

Макеты хранятся **отдельно для каждого монитора**: экраны различаются формой и
размером, и одно деление никогда не подходит всем. Мониторы опознаются по UUID,
поэтому настройки переживают отключение и перезагрузку.

### Визуальный редактор

**Изменить макет…** открывает редактор сразу на всех подключённых мониторах.
Настраивайте каждый отдельно; кнопка «Сохранить» на любом из них сохраняет все.
Размеры показаны в процентах, так что доли читать не приходится.

| Действие | Что делает |
| --- | --- |
| **Правый щелчок по зоне** | Разделить на 2 или 3, распределить поровну, поставить по центру |
| **Кнопка «Объединить» на границе** | Соединяет две зоны. Появляется там, где они дают прямоугольник |
| Перетащить границу | Двигает её. Зоны с обеих сторон тянутся следом, дыр не остаётся |
| Перетащить границу **с ⌥** | Двигает и зеркальную границу, симметрично центру экрана — чтобы равномерно расширить среднюю зону |
| Двойной щелчок по зоне | Разрезает её в этом месте вдоль длинной стороны (⌥ меняет направление) |
| `V` `H` `⌫` `⌘Z` `R` | Разделить, разделить иначе, объединить с соседней, отменить, сбросить |
| `return` / `esc` | Сохранить и закрыть / отказаться |

«Распределить этот столбец» выравнивает зоны, стоящие друг над другом в одном
столбце (скажем, четыре вдоль левого края); для ряда выравниваются ширины. Зоны
такого же размера в другом месте экрана не трогаются.

«По центру экрана» смещает зону так, чтобы она стояла симметрично средней линии, не
меняя размера. Зона, прижатая к краю экрана, так двигаться не может — пункт меню
остаётся выключенным.

Границы прилипают к краям других зон и к 1/4, 1/3, 1/2, 2/3 и 3/4. Настройка
**Зазор** внизу задаёт промежуток между зонами; выберите «Нет», чтобы окна стояли
вплотную.

### Макеты и история

**Макеты…** перечисляет каждый монитор: подключён ли он, что в нём и когда его
использовали в последний раз. Настройки монитора, которого у вас больше нет, сразу
заметны и удаляются одним нажатием.

Каждое сохранение оставляет прежнее состояние в `~/.config/waridake/history/` —
последние 10 версий. Любую можно восстановить из списка, а состояние до
восстановления тоже архивируется, так что ничего не теряется.

## Настройки

Файл — `~/.config/waridake/layout.json`, создаётся при первом запуске. Это обычный
файл: встроенный редактор — удобство, а не обязанность.

Каждая зона записывается как **доля от 0 до 1** от рабочей области экрана (того, что
оставляют строка меню и Dock). `x`/`y` отсчитываются от левого верхнего угла, `w`/`h` —
ширина и высота, `gap` — промежуток между зонами в пунктах.

По умолчанию — два равных столбца:

```json
{
  "gap": 8,
  "zones": [
    { "x": 0,   "y": 0, "w": 0.5, "h": 1 },
    { "x": 0.5, "y": 0, "w": 0.5, "h": 1 }
  ]
}
```

Зоны могут перекрываться; побеждает первая, внутри которой оказался курсор.

### Макеты по мониторам

Мониторы идут в `displays`, ключ — UUID монитора. Визуальный редактор пишет это за
вас. Мониторы без записи используют `gap` / `zones` верхнего уровня. `name` и
`usedAt` — служебные пометки, их пишет только программа.

```json
{
  "gap": 8,
  "zones": [
    { "x": 0,   "y": 0, "w": 0.5, "h": 1 },
    { "x": 0.5, "y": 0, "w": 0.5, "h": 1 }
  ],
  "displays": {
    "37D8832A-2D66-02CA-B9F7-8F30A301B230": {
      "name": "Studio Display",
      "usedAt": "2026-08-13T12:25:00Z",
      "gap": 0,
      "zones": [
        { "x": 0,    "y": 0, "w": 0.25, "h": 1 },
        { "x": 0.25, "y": 0, "w": 0.5,  "h": 1 },
        { "x": 0.75, "y": 0, "w": 0.25, "h": 1 }
      ]
    }
  }
}
```

Файлы без `displays` по-прежнему читаются и действуют везде.

## Языки

26 языков, выбираются автоматически по языковым настройкам macOS — настраивать
нечего.

Большинство переводов сделаны не носителями, поэтому исправления — самый желанный
вид pull request. Добавить язык значит скопировать
`Resources/en.lproj/Localizable.strings` в `Resources/<язык>.lproj/`, перевести правую
часть каждой строки и пересобрать. Непереведённое возвращается к английскому.

## Как это устроено

- Глобальный монитор событий следит за перетаскиванием левой кнопкой (именно из-за
  этого нужен универсальный доступ)
- При нажатии окно под курсором находится через Accessibility API
- Зоны появляются только после того, как **сдвинулось само окно**: выделение текста
  или перетаскивание файла внутри окна ничего не запускает
- Отпустили Shift — зоны исчезают, перетаскивание продолжается как обычно

## Если что-то не так

- **Зоны не появляются** — проверьте разрешение; пока его нет, в меню виден пункт с ⚠️
- **Перестало работать после пересборки** — см. «О пересборке»
- **Одна программа не встаёт в зону** — она отказывается менять размер. Программы с
  минимальным размером окна, включая некоторые на Electron, остаются больше зоны
