เครื่องมือจัดวางหน้าต่างบน macOS ที่ทำแค่แบ่งหน้าจอเท่านั้น

*Waridake* (割り竹) แปลว่า “ไม้ไผ่ผ่าซีก” — ฟันเดียวให้ขาด ไม่มีอะไรมากกว่านั้น

**มันทำอะไร:**

1. คุณกำหนดโซนของแต่ละจอไว้
2. **กด Shift ค้างไว้ขณะลากหน้าต่าง** แล้วโซนจะปรากฏขึ้น
3. ปล่อยเหนือโซนใด หน้าต่างก็เข้าไปพอดีในโซนนั้น

ไม่มีตารางปุ่มลัด ไม่มีประวัติหน้าต่าง ไม่มีค่าสมาชิกรายเดือน มันอยู่บนแถบเมนูเท่านั้น

> ฉบับภาษาอังกฤษ [README.md](README.md) ถือเป็นฉบับหลัก หากคำแปลนี้ตามไม่ทัน ให้ยึดฉบับอังกฤษ

## การติดตั้ง

ต้องมี Xcode Command Line Tools (`xcode-select --install`)

```bash
git clone https://github.com/omikuji/waridake.git
cd waridake
make install   # → /Applications/Waridake.app
```

เมื่อเปิดครั้งแรก macOS จะขอสิทธิ์การช่วยการเข้าถึง ให้เปิด Waridake ใน
**การตั้งค่าระบบ → ความเป็นส่วนตัวและความปลอดภัย → การช่วยการเข้าถึง**
อนุญาตขณะแอปกำลังทำงานก็พอ มันจะรู้ตัวภายในหนึ่งวินาที ไม่ต้องเปิดใหม่

หากต้องการให้เปิดตอนเข้าสู่ระบบ: การตั้งค่าระบบ → ทั่วไป → รายการเข้าสู่ระบบ

### ข้อควรรู้เมื่อคอมไพล์ใหม่

โดยปริยายจะเซ็นแบบ ad hoc ดังนั้น **ลายเซ็นจะเปลี่ยนทุกครั้งที่คอมไพล์ และ macOS จะถอนสิทธิ์เงียบ ๆ**
ช่องยังติ๊กอยู่แต่ใช้งานไม่ได้ ให้ลบ Waridake ออกจากรายการแล้วเพิ่มใหม่ หรือแก้ให้จบด้วยการสร้าง
ใบรับรองสำหรับเซ็นโค้ดแบบเซ็นเอง (Keychain Access → ผู้ช่วยใบรับรอง → สร้างใบรับรอง ชนิด: code signing)
แล้วคอมไพล์ด้วยใบรับรองนั้น:

```bash
make install SIGN_IDENTITY="Waridake Dev"
```

## วิธีใช้

ทุกอย่างอยู่ใต้ไอคอนบนแถบเมนู

| รายการเมนู | หน้าที่ |
| --- | --- |
| **จัดหน้าต่างที่เปิดอยู่** | ย้ายทุกหน้าต่างที่เปิดอยู่ไปยังโซนที่ใกล้ที่สุด ใช้เก็บกวาดเมื่อหน้าต่างเลื่อนออกไป |
| **แก้ไขเลย์เอาต์…** | ตัวแก้ไขแบบกราฟิก อธิบายไว้ด้านล่าง |
| **รายการเลย์เอาต์…** | เลย์เอาต์แยกตามจอพร้อมวันที่ใช้ล่าสุด และประวัติการแก้ไข |
| **แก้ไขเป็น JSON…** | ไฟล์ตั้งค่าในหน้าต่างแก้ไขเรียบ ๆ |
| **โหลดเลย์เอาต์ใหม่** | อ่านไฟล์อีกครั้งหลังคุณไปแก้ที่อื่น |

เลย์เอาต์เก็บ**แยกตามจอ** เพราะจอแต่ละตัวรูปทรงและขนาดต่างกัน การแบ่งแบบเดียวย่อมไม่เหมาะกับทุกจอ
จอถูกจำแนกด้วย UUID ดังนั้นการตั้งค่าจึงอยู่รอดทั้งการถอดสายและการรีสตาร์ต

### ตัวแก้ไขแบบกราฟิก

**แก้ไขเลย์เอาต์…** จะเปิดตัวแก้ไขบนทุกจอที่ต่ออยู่พร้อมกัน จัดแต่ละจอแยกกันได้ กด “บันทึก” ที่จอไหน
ก็บันทึกทั้งหมด ขนาดแสดงเป็นเปอร์เซ็นต์ จึงไม่ต้องอ่านเศษส่วนเลย

| การกระทำ | ผลลัพธ์ |
| --- | --- |
| **คลิกขวาที่โซน** | แบ่ง 2 หรือ 3 ส่วน กระจายให้เท่ากัน จัดกึ่งกลางจอ |
| **ปุ่ม “รวม” บนเส้นแบ่ง** | รวมสองโซนนั้นเข้าด้วยกัน ปรากฏตรงที่ทั้งคู่ประกอบเป็นสี่เหลี่ยม |
| ลากเส้นแบ่ง | เลื่อนเส้นนั้น โซนสองฝั่งยืดหดตามไปด้วย จึงไม่เกิดช่องว่าง |
| ลากเส้นแบ่ง **พร้อมกด ⌥** | เลื่อนเส้นที่สมมาตรอีกฝั่งไปด้วย โดยยึดกึ่งกลางจอ — ใช้ขยายโซนกลางให้เท่ากันสองข้าง |
| ดับเบิลคลิกที่โซน | ตัดตรงนั้นตามด้านที่ยาวกว่า (⌥ สลับทิศ) |
| `V` `H` `⌫` `⌘Z` `R` | แบ่ง แบ่งอีกทาง รวมกับโซนข้างเคียง เลิกทำ กลับค่าเริ่มต้น |
| `return` / `esc` | บันทึกแล้วปิด / ทิ้ง |

“กระจายคอลัมน์นี้ให้เท่ากัน” จะปรับโซนที่วางซ้อนกันในคอลัมน์เดียวกันให้เท่ากัน (เช่นสี่โซนตามขอบซ้าย)
ถ้าเป็นแถวก็ปรับความกว้าง โซนขนาดเท่ากันที่อยู่ตรงอื่นของจอจะไม่ถูกแตะต้อง

“จัดกึ่งกลางจอ” ย้ายโซนให้สมมาตรกับเส้นกึ่งกลางโดยไม่เปลี่ยนขนาด โซนที่ติดขอบจอย้ายแบบนั้นไม่ได้
รายการเมนูจึงถูกปิดไว้

เส้นแบ่งจะดูดเข้าหาขอบของโซนอื่น และตำแหน่ง 1/4, 1/3, 1/2, 2/3, 3/4 ส่วนตัวควบคุม **ระยะห่าง**
ด้านล่างกำหนดช่องไฟระหว่างโซน เลือก “ไม่มี” เพื่อให้หน้าต่างชิดกันสนิท

### รายการและประวัติ

**รายการเลย์เอาต์…** จะแสดงทุกจอพร้อมสถานะการเชื่อมต่อ เนื้อหา และเวลาที่ใช้ล่าสุด
การตั้งค่าของจอที่คุณไม่มีแล้วจึงสังเกตเห็นได้ทันทีและลบทิ้งได้

ทุกครั้งที่บันทึก สถานะก่อนหน้าจะถูกเก็บไว้ใน `~/.config/waridake/history/` เก็บ 10 รุ่นล่าสุด
เรียกคืนรุ่นไหนก็ได้จากรายการ และสถานะก่อนการเรียกคืนก็ถูกเก็บไว้เช่นกัน จึงไม่มีอะไรหาย

## การตั้งค่า

ไฟล์คือ `~/.config/waridake/layout.json` สร้างขึ้นตอนเปิดครั้งแรก มันเป็นไฟล์ธรรมดา —
ตัวแก้ไขในตัวมีไว้เพื่อความสะดวก ไม่ใช่ข้อบังคับ

แต่ละโซนเขียนเป็น **สัดส่วนระหว่าง 0 ถึง 1** ของพื้นที่ทำงานบนจอ (ส่วนที่เหลือจากแถบเมนูและ Dock)
`x`/`y` เริ่มจากมุมบนซ้าย `w`/`h` คือกว้างและสูง ส่วน `gap` คือระยะห่างระหว่างโซน หน่วยเป็นพอยต์

ค่าเริ่มต้นคือสองคอลัมน์เท่ากัน:

```json
{
  "gap": 8,
  "zones": [
    { "x": 0,   "y": 0, "w": 0.5, "h": 1 },
    { "x": 0.5, "y": 0, "w": 0.5, "h": 1 }
  ]
}
```

โซนซ้อนทับกันได้ โซนแรกที่ครอบตัวชี้เมาส์จะเป็นผู้ชนะ

### เลย์เอาต์แยกตามจอ

จอต่าง ๆ อยู่ใต้ `displays` โดยใช้ UUID ของจอเป็นคีย์ ตัวแก้ไขแบบกราฟิกจะเขียนให้เอง
จอที่ไม่มีรายการจะใช้ `gap` / `zones` ด้านบนสุด ส่วน `name` กับ `usedAt` เป็นบันทึกภายใน แอปเป็นผู้เขียน

```json
{
  "gap": 8,
  "zones": [
    { "x": 0,   "y": 0, "w": 0.5, "h": 1 },
    { "x": 0.5, "y": 0, "w": 0.5, "h": 1 }
  ],
  "displays": {
    "37D8832A-2D66-02CA-B9F7-8F30A301B230": {
      "name": "Studio Display",
      "usedAt": "2026-08-13T12:25:00Z",
      "gap": 0,
      "zones": [
        { "x": 0,    "y": 0, "w": 0.25, "h": 1 },
        { "x": 0.25, "y": 0, "w": 0.5,  "h": 1 },
        { "x": 0.75, "y": 0, "w": 0.25, "h": 1 }
      ]
    }
  }
}
```

ไฟล์ที่ไม่มี `displays` ก็ยังอ่านได้ และจะใช้กับทุกจอ

## ภาษา

26 ภาษา เลือกอัตโนมัติตามการตั้งค่าภาษาของ macOS — ไม่ต้องตั้งค่าอะไรเลย

ส่วนใหญ่ไม่ได้เขียนโดยเจ้าของภาษา การแก้คำแปลจึงเป็น pull request ที่ยินดีรับมากที่สุด
การเพิ่มภาษาทำได้โดยคัดลอก `Resources/en.lproj/Localizable.strings` ไปไว้ที่
`Resources/<ภาษา>.lproj/` แล้วแปลข้อความฝั่งขวาของแต่ละบรรทัด จากนั้นคอมไพล์ใหม่
ส่วนที่ยังไม่ได้แปลจะย้อนกลับไปใช้ภาษาอังกฤษ

## หลักการทำงาน

- ตัวเฝ้าดูเหตุการณ์ระดับระบบคอยดูการลากด้วยปุ่มซ้าย (นี่คือเหตุผลที่ต้องขอสิทธิ์การช่วยการเข้าถึง)
- เมื่อกดลง จะหาหน้าต่างใต้ตัวชี้ผ่าน Accessibility API
- โซนจะปรากฏก็ต่อเมื่อ **ตัวหน้าต่างขยับแล้วเท่านั้น** การเลือกข้อความหรือลากไฟล์ในหน้าต่างจึงไม่ทำให้เกิดอะไร
- ปล่อย Shift แล้วโซนจะหายไป และการลากดำเนินต่อไปตามปกติ

## แก้ปัญหา

- **ไม่มีโซนปรากฏ** — ตรวจสิทธิ์การช่วยการเข้าถึง ถ้ายังไม่ได้ให้ เมนูจะมีรายการ ⚠️ อยู่
- **คอมไพล์ใหม่แล้วใช้ไม่ได้** — ดู “ข้อควรรู้เมื่อคอมไพล์ใหม่” ด้านบน
- **มีบางแอปไม่ยอมเข้าที่** — แอปนั้นปฏิเสธการเปลี่ยนขนาด แอปที่กำหนดขนาดหน้าต่างขั้นต่ำ
  รวมถึงบางแอปที่ใช้ Electron จะใหญ่กว่าโซน
