# Waridake(割り竹)

画面を割るだけの macOS ウィンドウスナップアプリ。

**できること:**

1. ディスプレイごとにゾーンを決めておく
2. ウィンドウをドラッグ中に **Shift を押すとゾーンが表示される**
3. ゾーンの上でマウスを離すと、そのゾーンにウィンドウがはまる

ホットキーの格子なし、ウィンドウ履歴なし、サブスクなし。メニューバー常駐のみ。

> 正典は英語版の [README.md](../README.md)。この訳が遅れている場合は英語版が優先。

## インストール

Xcode Command Line Tools が必要(`xcode-select --install`)。

```bash
git clone https://github.com/omikuji/waridake.git
cd waridake
make install   # → /Applications/Waridake.app
```

初回起動時にアクセシビリティ許可を求められる。
**システム設定 → プライバシーとセキュリティ → アクセシビリティ** で Waridake を ON にする。
起動したまま許可しても1秒ほどで反映されるので、再起動は不要。

ログイン時に起動したい場合は、システム設定 → 一般 → ログイン項目 に Waridake.app を追加する。

### 再ビルド時の注意

既定ではアドホック署名なので、**再ビルドのたびに署名が変わり、macOS が黙ってアクセシビリティ許可を無効化する**。
一覧のチェックは入ったままなのに動かない、という状態になる。
アクセシビリティ一覧から Waridake を一度削除して再登録するか、
自己署名のコード署名証明書を作れば根本的に解決する
(キーチェーンアクセス → 証明書アシスタント → 証明書を作成、種類は「コード署名」)。

```bash
make install SIGN_IDENTITY="Waridake Dev"
```

## 使い方

操作はすべてメニューバーのアイコンから。

| メニュー項目 | できること |
| --- | --- |
| **開いているウィンドウを整列** | 開いている全ウィンドウを、いちばん近いゾーンに入れ直す。ズレたときの立て直し用 |
| **レイアウトを編集…** | 下で説明する GUI エディタ |
| **レイアウト一覧…** | ディスプレイごとの設定(最終利用日つき)と編集履歴 |
| **JSON で編集…** | 設定ファイルをそのままテキストで編集 |
| **レイアウトを再読み込み** | 外部エディタで直したあとに読み直す |

レイアウトは**ディスプレイごとに別々**に持つ。画面の形も広さも違うので、
1つの割り方を全部に当てても合わないため。ディスプレイの見分けには UUID を
使うので、抜き差しや再起動をまたいでも設定は残る。

### GUI エディタ

**レイアウトを編集…** を選ぶと、つないでいる**全ディスプレイに同時に**エディタが出る。
それぞれの画面で組んで、どれか1つで「保存」を押せばまとめて保存される。
大きさは % で表示されるので、割合の数字を読む必要はない。

| 操作 | できること |
| --- | --- |
| **ゾーンを右クリック** | 2分割・3分割、等間隔、中央揃え |
| **境界線の「結合」ボタン** | その2枚を1枚にする。つないで長方形になる組にだけ出る |
| 境界線をドラッグ | 境界を動かす。両側のゾーンが一緒に伸び縮みするので隙間ができない |
| 境界線を **⌥ ドラッグ** | 画面中央を軸に反対側の境界も対称に動く。中央のゾーンを左右均等に広げる用 |
| ゾーンをダブルクリック | その位置で分割(長い方の辺で割る。⌥ で向きを反転) |
| `V` `H` `⌫` `⌘Z` `R` | 分割 / 逆向きに分割 / 隣と結合 / 取り消し / 初期状態 |
| `return` / `esc` | 保存して閉じる / 破棄 |

「この列を等間隔にする」は、同じ列に縦に並んだゾーン(左端を4分割している場合など)の
高さを揃える。行なら幅を揃える。画面の別の場所にある同じ大きさのゾーンは巻き込まない。

「画面の中央に揃える」は大きさを変えずに、中央線に対して対称の位置へ動かす。
画面の外周に接しているゾーンは動かせないので、その場合は項目が無効になる。

境界線は他のゾーンの線と 1/4・1/3・1/2・2/3・3/4 に吸い付く。
下のバーの **「隙間」** でゾーン間の余白を変えられる。「なし」を選べばぴったり詰まる。

### 一覧と履歴

**レイアウト一覧…** には、ディスプレイごとの設定が、接続中かどうか・内容・
最終利用日つきで並ぶ。もう持っていないモニタの設定を見つけて削除できる。

いちばん上の行が **既定** で、自分のレイアウトを持たない画面が最初に使うもの。
どの行の **「既定にする」** を押しても、その画面の割り方が既定になる。
JSON を触らずに既定を変えるにはこれを使う。

保存するたびに直前の状態が `~/.config/waridake/history/` に残る(最新10世代)。
一覧からいつでも復元でき、復元前の状態も履歴に積まれるので戻し直せる。

## 設定ファイル

設定ファイルは `~/.config/waridake/layout.json`(初回起動時に自動生成)。
ただのファイルなので、内蔵エディタは便利のためであって必須ではない。

各ゾーンは画面の作業領域(メニューバー・Dock を除く)に対する **0〜1 の割合** で書く。
`x`/`y` は左上が原点、`w`/`h` が幅と高さ、`gap` はゾーン間の隙間(ポイント)。

既定は等幅2カラム:

```json
{
  "gap": 8,
  "zones": [
    { "x": 0,   "y": 0, "w": 0.5, "h": 1 },
    { "x": 0.5, "y": 0, "w": 0.5, "h": 1 }
  ]
}
```

ゾーンは重なっていてもよい(マウス位置に最初にヒットしたものが選ばれる)。

### ディスプレイごとの設定

`displays` にディスプレイ UUID をキーにして書く。GUI エディタで保存すると
この形で書き出される。`displays` に無いディスプレイには、いちばん外側の
`gap` / `zones` が使われる。`name` と `usedAt` は記録用で、アプリが書く。

```json
{
  "gap": 8,
  "zones": [
    { "x": 0,   "y": 0, "w": 0.5, "h": 1 },
    { "x": 0.5, "y": 0, "w": 0.5, "h": 1 }
  ],
  "displays": {
    "37D8832A-2D66-02CA-B9F7-8F30A301B230": {
      "name": "Studio Display",
      "usedAt": "2026-08-13T12:25:00Z",
      "gap": 0,
      "zones": [
        { "x": 0,    "y": 0, "w": 0.25, "h": 1 },
        { "x": 0.25, "y": 0, "w": 0.5,  "h": 1 },
        { "x": 0.75, "y": 0, "w": 0.25, "h": 1 }
      ]
    }
  }
}
```

`displays` を書かない前の形式の設定ファイルもそのまま読める(全画面に既定が使われる)。

## 対応言語

26言語。macOS の言語設定から自動的に選ばれるので、設定は不要:

アラビア語、イタリア語、インドネシア語、ウクライナ語、オランダ語、韓国語、
スウェーデン語、スペイン語、タイ語、中国語(簡体字・繁体字)、チェコ語、デンマーク語、
ドイツ語、トルコ語、ノルウェー語、ヒンディー語、フィンランド語、フランス語、
ヘブライ語、ベトナム語、ポーランド語、ポルトガル語(ブラジル)、ロシア語、
英語、日本語。

母語話者による翻訳ではないものが大半なので、修正のプルリクエストがいちばんありがたい。
言語を足すには `Resources/en.lproj/Localizable.strings` を
`Resources/<言語>.lproj/` にコピーして、各行の右辺を訳してビルドし直すだけ。
訳が無いものは英語にフォールバックする。

この README も翻訳されている。英語以外は `translations/` にあり、
先頭のリンクから辿れる。正典は英語版で、言語を足したら
`python3 Tools/sync-readme-nav.py` を実行するとリンクが揃う。

## 動作の仕組み

- グローバルイベントモニタで左ドラッグを監視(アクセシビリティ許可が必要な理由)
- mouseDown 時にカーソル下のウィンドウを Accessibility API で特定
- **ウィンドウ自体が動いた**ことを確認してからゾーンを表示する
  (ウィンドウ内のテキスト選択やファイルドラッグには反応しない)
- Shift を離すとゾーンは消え、何もせずに普通のドラッグに戻る

## トラブルシュート

- **メニューバーにアイコンが出ない** → メニューバーが満杯だと、入りきらない項目は
  macOS に隠される(ノッチ付きの Mac で起こりやすい)。**Waridake をもう一度開けば**
  (Spotlight・Finder・Dock)同じメニューがマウス位置に出る。アイコン自体を戻すには、
  他のメニューバーアプリを終了するか、⌘ を押しながらアイコンをドラッグして並べ替える
- **ゾーンが出ない** → アクセシビリティ許可を確認(未許可ならメニューに ⚠️ が出る)
- **再ビルド後に効かなくなった** → 上記「再ビルド時の注意」
- **特定アプリだけはまらない** → そのアプリがリサイズを拒否している。
  最小サイズ制約のあるアプリ(Electron 系の一部など)はゾーンより大きくなることがある
