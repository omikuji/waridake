أداة لترتيب النوافذ على macOS لا تفعل شيئًا سوى تقسيم الشاشة.

كلمة *Waridake* (割り竹) تعني «الخيزران المشقوق»: قطعة واحدة نظيفة، لا أكثر.

**ما تفعله:**

1. تحدّد المناطق لكل شاشة
2. اضغط **Shift أثناء سحب نافذة** فتظهر المناطق
3. اترك النافذة فوق منطقة فتستقر فيها

بلا شبكات اختصارات، بلا سجلّ نوافذ، بلا اشتراكات. تسكن في شريط القوائم.

> المرجع هو ملف [README.md](../README.md) الإنجليزي. إن تأخّرت هذه الترجمة فالنسخة
> الإنجليزية هي المعتمدة.

## التثبيت

يلزم توفّر أدوات سطر الأوامر لـ Xcode (`xcode-select --install`).

```bash
git clone https://github.com/omikuji/waridake.git
cd waridake
make install   # → /Applications/Waridake.app
```

عند أول تشغيل يطلب macOS إذن إمكانية الوصول. فعّل Waridake من **إعدادات النظام ←
الخصوصية والأمان ← إمكانية الوصول**. يكفي منح الإذن والتطبيق يعمل: سينتبه خلال ثانية،
ولا حاجة لإعادة تشغيله.

لتشغيله عند تسجيل الدخول: إعدادات النظام ← عام ← عناصر تسجيل الدخول.

### ملاحظة عند إعادة البناء

التوقيع افتراضيًا مؤقّت (ad hoc)، لذا **يتغيّر مع كل بناء ويسحب macOS الإذن بصمت** —
يبقى المربّع مؤشَّرًا لكن لا شيء يعمل. احذف Waridake من قائمة إمكانية الوصول ثم أضفه من
جديد، أو احسم الأمر بإنشاء شهادة توقيع برمجي ذاتية التوقيع (الوصول إلى سلسلة المفاتيح ←
مساعد الشهادات ← إنشاء شهادة، النوع: توقيع البرامج) وابنِ بها:

```bash
make install SIGN_IDENTITY="Waridake Dev"
```

## الاستخدام

كل شيء تحت أيقونة شريط القوائم.

| عنصر القائمة | ما يفعله |
| --- | --- |
| **ترتيب النوافذ المفتوحة** | يضع كل نافذة مفتوحة في أقرب منطقة إليها. للترتيب بعد أن تنزاح النوافذ |
| **تحرير التخطيط…** | المحرّر المرئي، الموصوف أدناه |
| **التخطيطات…** | تخطيط كل شاشة مع تاريخ آخر استخدام، وسجل التحرير |
| **تحرير بصيغة JSON…** | ملف الإعدادات في نافذة تحرير بسيطة |
| **إعادة تحميل التخطيط** | يقرأ الملف من جديد بعد تعديله في مكان آخر |

تُحفظ التخطيطات **لكل شاشة على حدة**، لأن الشاشات تختلف شكلًا وحجمًا ولا يناسبها جميعًا
تقسيم واحد. تُعرَّف الشاشات بمعرّفها UUID، فتبقى الإعدادات بعد الفصل وإعادة التشغيل.

### المحرّر المرئي

يفتح **تحرير التخطيط…** محرّرًا على كل الشاشات الموصولة في آن واحد. صمّم كل شاشة على حدة؛
والضغط على «حفظ» في أي منها يحفظها كلها. تظهر المقاسات بالنسبة المئوية، فلا داعي لقراءة
الكسور.

| الإجراء | ما يفعله |
| --- | --- |
| **نقر بالزر الأيمن على منطقة** | تقسيم إلى ٢ أو ٣، توزيع بالتساوي، توسيط على الشاشة |
| **زر «دمج» على أحد الحدود** | يضم المنطقتين في واحدة. يظهر حيث تشكّلان معًا مستطيلًا |
| سحب أحد الحدود | يحرّكه. تتمدّد المنطقتان على الجانبين معه، فلا تنشأ فجوات |
| سحب الحد **مع ⌥** | يحرّك أيضًا الحد المقابل بتناظر حول مركز الشاشة — لتوسيع المنطقة الوسطى بالتساوي |
| نقر مزدوج على منطقة | يقصّها عند تلك النقطة على امتداد ضلعها الأطول (⌥ يعكس الاتجاه) |
| `V` `H` `⌫` `⌘Z` `R` | تقسيم، تقسيم بالاتجاه الآخر، دمج مع مجاورة، تراجع، العودة للبداية |
| `return` / `esc` | حفظ وإغلاق / تجاهل |

«توزيع هذا العمود بالتساوي» يسوّي المناطق المرصوفة فوق بعضها في العمود ذاته (أربعة على
الحافة اليسرى مثلًا)؛ أما في الصف فيسوّي العروض. أما المناطق المماثلة في الحجم في مكان آخر
من الشاشة فتُترك كما هي.

«توسيط على الشاشة» ينقل المنطقة لتصير متناظرة حول الخط الأوسط دون تغيير حجمها. المنطقة
الملاصقة لحافة الشاشة لا يمكنها التحرك هكذا، فيبقى عنصر القائمة معطّلًا.

تلتصق الحدود بحواف المناطق الأخرى وبالمواضع ١/٤ و١/٣ و١/٢ و٢/٣ و٣/٤. ويضبط عنصر **الفجوة**
في الأسفل المسافة بين المناطق؛ اختر «بلا» لتتلاصق النوافذ.

### التخطيطات والسجل

تسرد **التخطيطات…** كل شاشة مع بيان اتصالها ومحتواها وآخر استخدام لها، فتبرز فورًا إعدادات
شاشة لم تعد تملكها ويمكن حذفها.

كل حفظ يترك الحالة السابقة في `~/.config/waridake/history/`، وتُحفظ آخر ١٠ نسخ. يمكن استعادة
أي منها من القائمة، كما تُؤرشف الحالة السابقة للاستعادة نفسها، فلا يضيع شيء.

## الإعدادات

الملف هو `~/.config/waridake/layout.json`، ويُنشأ عند أول تشغيل. هو ملف عادي تمامًا —
والمحرّر المدمج راحة لا شرط.

تُكتب كل منطقة **كنسبة بين ٠ و١** من مساحة العمل على الشاشة (ما يتركه شريط القوائم والـ Dock).
يبدأ `x`/`y` من أعلى اليسار، و`w`/`h` هما العرض والارتفاع، و`gap` هو المسافة بين المناطق
بالنقاط.

الافتراضي عمودان متساويان:

```json
{
  "gap": 8,
  "zones": [
    { "x": 0,   "y": 0, "w": 0.5, "h": 1 },
    { "x": 0.5, "y": 0, "w": 0.5, "h": 1 }
  ]
}
```

يجوز تداخل المناطق؛ وتفوز أولى المناطق التي يقع فيها المؤشر.

### تخطيط لكل شاشة

تُدرج الشاشات تحت `displays` ومفتاحها معرّف الشاشة UUID. المحرّر المرئي يكتب ذلك عنك. أما
الشاشات بلا مدخل فتستعمل `gap` / `zones` في الأعلى. و`name` و`usedAt` مجرد تدوين — لا يكتبهما
سوى التطبيق.

```json
{
  "gap": 8,
  "zones": [
    { "x": 0,   "y": 0, "w": 0.5, "h": 1 },
    { "x": 0.5, "y": 0, "w": 0.5, "h": 1 }
  ],
  "displays": {
    "37D8832A-2D66-02CA-B9F7-8F30A301B230": {
      "name": "Studio Display",
      "usedAt": "2026-08-13T12:25:00Z",
      "gap": 0,
      "zones": [
        { "x": 0,    "y": 0, "w": 0.25, "h": 1 },
        { "x": 0.25, "y": 0, "w": 0.5,  "h": 1 },
        { "x": 0.75, "y": 0, "w": 0.25, "h": 1 }
      ]
    }
  }
}
```

الملفات الخالية من `displays` تُقرأ كما هي وتسري على الجميع.

## اللغات

٢٦ لغة تُختار تلقائيًا من إعدادات لغة macOS لديك — لا شيء يحتاج ضبطًا.

معظمها لم يكتبه ناطقون أصليون، لذا فإن التصحيحات هي أحبّ أنواع طلبات السحب. إضافة لغة تعني
نسخ `Resources/en.lproj/Localizable.strings` إلى `Resources/<اللغة>.lproj/` وترجمة الطرف
الأيمن من كل سطر ثم إعادة البناء. وما لا يُترجم يعود إلى الإنجليزية.

## كيف يعمل

- مراقب أحداث عام يتابع السحب بالزر الأيسر (وهذا سبب الحاجة إلى إذن إمكانية الوصول)
- عند الضغط تُحدَّد النافذة الواقعة تحت المؤشر عبر واجهة إمكانية الوصول
- لا تظهر المناطق إلا بعد أن **تتحرك النافذة نفسها**، فتحديد نص أو سحب ملف داخل نافذة لا يُطلق
  شيئًا
- بترك مفتاح Shift تختفي المناطق ويمضي السحب كالمعتاد

## معالجة المشكلات

- **لا تظهر أي مناطق** — تحقّق من إذن إمكانية الوصول؛ وما دام ناقصًا تعرض القائمة عنصرًا بعلامة ⚠️
- **توقّف عن العمل بعد إعادة بناء** — راجع «ملاحظة عند إعادة البناء»
- **تطبيق واحد يأبى الانضباط** — إنه يرفض تغيير الحجم. التطبيقات ذات الحد الأدنى لحجم النافذة،
  ومنها بعض تطبيقات Electron، تبقى أكبر من المنطقة
