macOS के लिए एक विंडो-व्यवस्थापक, जो सिर्फ़ स्क्रीन बाँटने का काम करता है।

*Waridake* (割り竹) का अर्थ है “चिरा हुआ बाँस” — एक साफ़ वार, बस इतना ही।

**यह क्या करता है:**

1. आप हर डिस्प्ले के लिए ज़ोन तय करते हैं
2. **विंडो खींचते समय Shift दबाए रखें**, ज़ोन दिखने लगते हैं
3. किसी ज़ोन पर छोड़ दीजिए, विंडो उसी में बैठ जाती है

न शॉर्टकट की जालियाँ, न विंडो का इतिहास, न कोई सदस्यता। यह मेन्यू बार में रहता है।

> मूल दस्तावेज़ अंग्रेज़ी वाला [README.md](../README.md) है। यदि यह अनुवाद पीछे रह जाए, तो
> अंग्रेज़ी वाला ही मान्य है।

## संस्थापन

Xcode कमांड लाइन टूल्स चाहिए (`xcode-select --install`)।

```bash
git clone https://github.com/omikuji/waridake.git
cd waridake
make install   # → /Applications/Waridake.app
```

पहली बार चलाने पर macOS ऐक्सेसिबिलिटी की अनुमति माँगता है। **सिस्टम सेटिंग्स → प्राइवेसी और
सुरक्षा → ऐक्सेसिबिलिटी** में Waridake को चालू कर दें। ऐप चलते-चलते अनुमति देना काफ़ी है — वह एक
सेकंड में भाँप लेता है, दोबारा शुरू करने की ज़रूरत नहीं।

लॉगिन पर चलाना हो तो: सिस्टम सेटिंग्स → सामान्य → लॉगिन आइटम्स।

### दोबारा बनाते समय ध्यान दें

डिफ़ॉल्ट रूप से हस्ताक्षर ad-hoc होता है, इसलिए **हर बार बनाने पर हस्ताक्षर बदल जाता है और macOS
चुपचाप अनुमति वापस ले लेता है** — चेकबॉक्स लगा दिखता है, पर कुछ काम नहीं करता। Waridake को
ऐक्सेसिबिलिटी सूची से हटाकर दोबारा जोड़ें, या जड़ से हल करें: किचेन एक्सेस में स्वयं-हस्ताक्षरित
कोड साइनिंग प्रमाणपत्र बनाएँ (सर्टिफ़िकेट असिस्टेंट → सर्टिफ़िकेट बनाएँ, प्रकार: कोड साइनिंग) और
उसी से बनाएँ:

```bash
make install SIGN_IDENTITY="Waridake Dev"
```

## इस्तेमाल

सब कुछ मेन्यू बार के आइकन के नीचे है।

| मेन्यू आइटम | क्या करता है |
| --- | --- |
| **खुली विंडो व्यवस्थित करें** | हर खुली विंडो को उसके सबसे नज़दीकी ज़ोन में रख देता है। विंडो खिसक जाएँ तो सँवारने के लिए |
| **लेआउट संपादित करें…** | नीचे बताया गया दृश्य संपादक |
| **लेआउट सूची…** | हर डिस्प्ले का लेआउट, आख़िरी उपयोग की तारीख़ के साथ, और संपादन इतिहास |
| **JSON के रूप में संपादित करें…** | सेटिंग फ़ाइल, एक सादे संपादन विंडो में |
| **लेआउट फिर से लोड करें** | कहीं और बदलने के बाद फ़ाइल दोबारा पढ़ता है |

लेआउट **हर डिस्प्ले के लिए अलग** रखे जाते हैं, क्योंकि स्क्रीनों का आकार-प्रकार अलग होता है और एक ही
बँटवारा सब पर नहीं जँचता। डिस्प्ले उनके UUID से पहचाने जाते हैं, इसलिए केबल निकालने या कंप्यूटर
दोबारा चालू करने पर भी सेटिंग बनी रहती है।

### दृश्य संपादक

**लेआउट संपादित करें…** चुनते ही जुड़े हुए सभी डिस्प्ले पर एक साथ संपादक खुल जाता है। हर स्क्रीन को
अलग-अलग गढ़िए; किसी एक पर सहेजें दबाते ही सब सहेजे जाते हैं। आकार प्रतिशत में दिखते हैं, सो भिन्नें
पढ़ने की नौबत नहीं आती।

| क्रिया | क्या करती है |
| --- | --- |
| **ज़ोन पर राइट-क्लिक** | 2 या 3 में बाँटना, बराबर बाँटना, स्क्रीन के बीच में लाना |
| **सीमा पर “मिलाएँ” बटन** | उन दोनों ज़ोन को एक कर देता है। वहीं दिखता है जहाँ दोनों मिलकर आयत बनाते हों |
| सीमा खींचना | उसे सरकाता है। दोनों ओर के ज़ोन साथ-साथ फैलते-सिकुड़ते हैं, इसलिए ख़ाली जगह नहीं बनती |
| सीमा को **⌥ के साथ खींचना** | स्क्रीन के केंद्र के सापेक्ष दर्पण-सीमा को भी सरकाता है — बीच वाले ज़ोन को दोनों ओर बराबर चौड़ा करने के लिए |
| ज़ोन पर डबल-क्लिक | उसी जगह, लंबी भुजा के साथ काटता है (⌥ दिशा उलट देता है) |
| `V` `H` `⌫` `⌘Z` `R` | बाँटना, उलटी दिशा में बाँटना, पड़ोसी से मिलाना, पूर्ववत करना, शुरुआत पर लौटना |
| `return` / `esc` | सहेजकर बंद करना / छोड़ देना |

“इस कॉलम को बराबर बाँटें” एक ही कॉलम में ऊपर-नीचे लगे ज़ोन को बराबर कर देता है (जैसे बाएँ किनारे पर
चार); पंक्ति के लिए चौड़ाइयाँ बराबर होती हैं। स्क्रीन पर कहीं और मौजूद उतने ही बड़े ज़ोन को हाथ नहीं
लगाया जाता।

“स्क्रीन के बीच में लाएँ” ज़ोन का आकार बदले बिना उसे केंद्र-रेखा के सापेक्ष सममित जगह पर ले जाता है।
स्क्रीन के किनारे से सटा ज़ोन इस तरह नहीं हिल सकता, इसलिए वह मेन्यू आइटम निष्क्रिय रहता है।

सीमाएँ दूसरे ज़ोन के किनारों तथा 1/4, 1/3, 1/2, 2/3 और 3/4 पर चिपकती हैं। नीचे दिया **अंतराल**
ज़ोन के बीच की जगह तय करता है; “कोई नहीं” चुनिए तो विंडो एक-दूसरे से सटी रहेंगी।

### सूची और इतिहास

**लेआउट सूची…** हर डिस्प्ले को इस ब्योरे के साथ दिखाती है कि वह जुड़ा है या नहीं, उसमें क्या है, और
आख़िरी बार कब इस्तेमाल हुआ — जो मॉनिटर अब आपके पास नहीं, उसकी सेटिंग तुरंत पकड़ में आती है और मिटाई
जा सकती है।

हर बार सहेजने पर पिछली स्थिति `~/.config/waridake/history/` में रह जाती है, अंतिम 10 संस्करण। सूची से
कभी भी कोई भी लौटाया जा सकता है, और लौटाने से पहले की स्थिति भी सुरक्षित रख ली जाती है, सो कुछ खोता
नहीं।

## विन्यास

फ़ाइल है `~/.config/waridake/layout.json`, जो पहली बार चलाने पर बनती है। यह एक सामान्य फ़ाइल है —
भीतर का संपादक सुविधा है, शर्त नहीं।

हर ज़ोन स्क्रीन के कार्यक्षेत्र (मेन्यू बार और डॉक के बाद बची जगह) के **0 से 1 के बीच के अनुपात** में
लिखा जाता है। `x`/`y` ऊपर-बाएँ से गिने जाते हैं, `w`/`h` चौड़ाई और ऊँचाई हैं, और `gap` ज़ोन के बीच का
अंतर है, पॉइंट में।

डिफ़ॉल्ट है बराबर चौड़ाई के दो कॉलम:

```json
{
  "gap": 8,
  "zones": [
    { "x": 0,   "y": 0, "w": 0.5, "h": 1 },
    { "x": 0.5, "y": 0, "w": 0.5, "h": 1 }
  ]
}
```

ज़ोन एक-दूसरे पर चढ़ सकते हैं; जिसमें सबसे पहले पॉइंटर आता है, वही जीतता है।

### हर डिस्प्ले के लेआउट

डिस्प्ले `displays` के नीचे आते हैं, कुंजी होती है डिस्प्ले का UUID। दृश्य संपादक यह आपके लिए लिख देता
है। जिन डिस्प्ले की प्रविष्टि नहीं, वे ऊपर वाले `gap` / `zones` इस्तेमाल करते हैं। `name` और `usedAt`
सिर्फ़ रिकॉर्ड हैं — उन्हें ऐप ही लिखता है।

```json
{
  "gap": 8,
  "zones": [
    { "x": 0,   "y": 0, "w": 0.5, "h": 1 },
    { "x": 0.5, "y": 0, "w": 0.5, "h": 1 }
  ],
  "displays": {
    "37D8832A-2D66-02CA-B9F7-8F30A301B230": {
      "name": "Studio Display",
      "usedAt": "2026-08-13T12:25:00Z",
      "gap": 0,
      "zones": [
        { "x": 0,    "y": 0, "w": 0.25, "h": 1 },
        { "x": 0.25, "y": 0, "w": 0.5,  "h": 1 },
        { "x": 0.75, "y": 0, "w": 0.25, "h": 1 }
      ]
    }
  }
}
```

`displays` के बिना वाली फ़ाइलें भी पढ़ी जाती हैं और सब जगह लागू होती हैं।

## भाषाएँ

26 भाषाएँ, जो आपकी macOS भाषा सेटिंग से अपने आप चुन ली जाती हैं — सेट करने को कुछ नहीं।

इनमें अधिकतर मातृभाषियों की लिखी नहीं हैं, इसलिए सुधार सबसे स्वागत-योग्य pull request है। भाषा
जोड़ने का मतलब है `Resources/en.lproj/Localizable.strings` को `Resources/<भाषा>.lproj/` में कॉपी
करना, हर पंक्ति का दायाँ हिस्सा अनुवाद करना और दोबारा बनाना। जो अनूदित न हो, वह अंग्रेज़ी पर लौट
आता है।

## यह काम कैसे करता है

- एक वैश्विक इवेंट मॉनिटर बाएँ बटन से खींचने पर नज़र रखता है (ऐक्सेसिबिलिटी अनुमति इसी के लिए चाहिए)
- बटन दबते ही पॉइंटर के नीचे की विंडो Accessibility API से खोजी जाती है
- ज़ोन तभी दिखते हैं जब **विंडो स्वयं हिल चुकी हो**, इसलिए विंडो के भीतर टेक्स्ट चुनने या फ़ाइल खींचने
  से कुछ नहीं होता
- Shift छोड़ते ही ज़ोन ग़ायब हो जाते हैं और खींचना सामान्य रूप से चलता रहता है

## समस्या निवारण

- **कोई ज़ोन नहीं दिखता** — ऐक्सेसिबिलिटी अनुमति देखिए; जब तक वह नहीं है, मेन्यू में ⚠️ वाला आइटम रहता है
- **दोबारा बनाने के बाद काम करना बंद** — ऊपर “दोबारा बनाते समय ध्यान दें” देखिए
- **कोई एक ऐप नहीं बैठता** — वह आकार बदलने से मना कर रहा है। न्यूनतम विंडो आकार वाले ऐप, जिनमें कुछ
  Electron वाले भी हैं, ज़ोन से बड़े रह जाते हैं
