화면을 나누는 일만 하는 macOS 창 배치 도구.

*Waridake*(割り竹)는 “쪼갠 대나무”라는 뜻입니다. 깔끔한 한 칼, 그뿐입니다.

**하는 일:**

1. 디스플레이마다 영역을 정해 둡니다
2. **창을 끌면서 Shift를 누르면** 영역이 나타납니다
3. 영역 위에서 손을 떼면 창이 그 자리에 맞춰집니다

단축키 격자도, 창 기록도, 구독도 없습니다. 메뉴 막대에만 머무릅니다.

> 영어판 [README.md](../README.md)가 기준입니다. 이 번역이 뒤처졌다면 영어판을 따르세요.

## 설치

Xcode 명령줄 도구가 필요합니다(`xcode-select --install`).

```bash
git clone https://github.com/omikuji/waridake.git
cd waridake
make install   # → /Applications/Waridake.app
```

처음 실행하면 macOS가 손쉬운 사용 권한을 요청합니다. **시스템 설정 → 개인정보 보호 및
보안 → 손쉬운 사용**에서 Waridake를 켜 주세요. 앱이 실행 중일 때 켜도 됩니다. 1초 안에
알아채므로 다시 시작할 필요가 없습니다.

로그인할 때 자동으로 열려면 시스템 설정 → 일반 → 로그인 항목에 Waridake.app을 추가하세요.

### 다시 빌드할 때 주의

기본은 애드혹 서명이라 **빌드할 때마다 서명이 바뀌고 macOS가 조용히 권한을 거둬 갑니다**.
체크는 켜져 있는데 아무것도 동작하지 않습니다. 손쉬운 사용 목록에서 Waridake를 지웠다가
다시 추가하거나, 아예 자체 서명한 코드 서명 인증서를 만들어 문제를 없애세요(키체인 접근 →
인증서 지원 → 인증서 생성, 유형: 코드 서명). 그다음 이렇게 빌드합니다:

```bash
make install SIGN_IDENTITY="Waridake Dev"
```

## 사용법

모든 기능은 메뉴 막대 아이콘 안에 있습니다.

| 메뉴 항목 | 하는 일 |
| --- | --- |
| **열려 있는 창 정리** | 열려 있는 창을 저마다 가장 가까운 영역에 넣습니다. 창이 어긋났을 때 정리용 |
| **레이아웃 편집…** | 아래에서 설명하는 그래픽 편집기 |
| **레이아웃 목록…** | 디스플레이별 레이아웃과 마지막 사용 시각, 그리고 편집 기록 |
| **JSON으로 편집…** | 설정 파일을 단순한 편집 창에서 |
| **레이아웃 다시 불러오기** | 다른 데서 파일을 고친 뒤 다시 읽습니다 |

레이아웃은 **디스플레이마다 따로** 보관합니다. 화면마다 모양과 크기가 달라 한 가지 분할이
모두에 맞을 리 없기 때문입니다. 디스플레이는 UUID로 구분하므로 뽑았다 꽂거나 재시동해도
설정이 남습니다.

### 그래픽 편집기

**레이아웃 편집…**을 고르면 연결된 모든 디스플레이에 한꺼번에 편집기가 열립니다. 화면마다
따로 짜고, 아무 화면에서나 저장을 누르면 전부 저장됩니다. 크기는 퍼센트로 보여 주므로
분수를 읽을 일이 없습니다.

| 조작 | 하는 일 |
| --- | --- |
| **영역에서 오른쪽 클릭** | 2등분·3등분, 균등 분배, 화면 가운데로 |
| **경계선의 ‘병합’ 버튼** | 두 영역을 하나로 합칩니다. 둘이 사각형을 이루는 곳에만 나타납니다 |
| 경계선 끌기 | 경계선을 옮깁니다. 양쪽 영역이 함께 늘고 줄어 빈틈이 생기지 않습니다 |
| 경계선 **⌥ 끌기** | 화면 중앙을 기준으로 대칭인 경계선도 함께 움직입니다. 가운데 영역을 고르게 넓힐 때 |
| 영역 더블 클릭 | 그 자리에서 긴 변을 따라 자릅니다(⌥로 방향 반전) |
| `V` `H` `⌫` `⌘Z` `R` | 나누기, 반대로 나누기, 옆과 병합, 실행 취소, 처음 상태 |
| `return` / `esc` | 저장하고 닫기 / 버리기 |

‘이 열을 균등하게’는 같은 열에 세로로 쌓인 영역들의 높이를 맞춥니다(예: 왼쪽 가장자리를
넷으로 나눈 경우). 행이라면 너비를 맞춥니다. 화면 다른 곳에 있는 같은 크기의 영역은
건드리지 않습니다.

‘화면 가운데로’는 크기를 그대로 둔 채 중앙선에 대칭이 되도록 옮깁니다. 화면 가장자리에
닿아 있는 영역은 그렇게 움직일 수 없어 메뉴 항목이 비활성 상태로 남습니다.

경계선은 다른 영역의 모서리와 1/4, 1/3, 1/2, 2/3, 3/4에 달라붙습니다. 아래쪽 **간격**으로
영역 사이의 여백을 정하며, ‘없음’을 고르면 창들이 딱 붙습니다.

### 목록과 기록

**레이아웃 목록…**에는 디스플레이마다 연결 여부, 내용, 마지막 사용 시각이 함께 나옵니다.
이제 쓰지 않는 모니터의 설정이 눈에 띄고, 지울 수 있습니다.

저장할 때마다 직전 상태가 `~/.config/waridake/history/`에 최근 10개까지 남습니다. 목록에서
언제든 되돌릴 수 있고, 되돌리기 직전 상태도 함께 보관되므로 잃어버리지 않습니다.

## 설정

설정 파일은 `~/.config/waridake/layout.json`이며 처음 실행할 때 만들어집니다. 그냥 평범한
파일이라, 내장 편집기는 편의일 뿐 필수가 아닙니다.

각 영역은 화면의 작업 영역(메뉴 막대와 Dock을 뺀 부분)에 대한 **0에서 1 사이의 비율**로
씁니다. `x`/`y`는 왼쪽 위가 기준이고, `w`/`h`는 너비와 높이, `gap`은 영역 사이 간격(포인트)입니다.

기본값은 같은 너비의 두 열입니다:

```json
{
  "gap": 8,
  "zones": [
    { "x": 0,   "y": 0, "w": 0.5, "h": 1 },
    { "x": 0.5, "y": 0, "w": 0.5, "h": 1 }
  ]
}
```

영역은 겹쳐도 됩니다. 포인터를 품은 첫 번째 영역이 이깁니다.

### 디스플레이별 레이아웃

디스플레이는 `displays` 아래에 UUID를 키로 적습니다. 그래픽 편집기가 알아서 써 줍니다.
항목이 없는 디스플레이는 맨 위의 `gap` / `zones`를 씁니다. `name`과 `usedAt`은 기록용이라
앱만 씁니다.

```json
{
  "gap": 8,
  "zones": [
    { "x": 0,   "y": 0, "w": 0.5, "h": 1 },
    { "x": 0.5, "y": 0, "w": 0.5, "h": 1 }
  ],
  "displays": {
    "37D8832A-2D66-02CA-B9F7-8F30A301B230": {
      "name": "Studio Display",
      "usedAt": "2026-08-13T12:25:00Z",
      "gap": 0,
      "zones": [
        { "x": 0,    "y": 0, "w": 0.25, "h": 1 },
        { "x": 0.25, "y": 0, "w": 0.5,  "h": 1 },
        { "x": 0.75, "y": 0, "w": 0.25, "h": 1 }
      ]
    }
  }
}
```

`displays`가 없는 예전 형식의 설정 파일도 그대로 읽히며, 모든 화면에 적용됩니다.

## 언어

26개 언어. macOS의 언어 설정에 따라 자동으로 골라지므로 따로 설정할 것이 없습니다.

대부분 원어민이 쓴 번역이 아니므로, 번역을 고쳐 주는 pull request가 가장 반갑습니다.
언어를 추가하려면 `Resources/en.lproj/Localizable.strings`를 `Resources/<언어>.lproj/`로
복사해 각 줄의 오른쪽을 옮기고 다시 빌드하면 됩니다. 번역이 없는 항목은 영어로 되돌아갑니다.

## 동작 방식

- 전역 이벤트 모니터가 왼쪽 버튼 끌기를 지켜봅니다(손쉬운 사용 권한이 필요한 이유)
- 누른 순간 포인터 아래의 창을 손쉬운 사용 API로 찾습니다
- **창 자체가 움직인 뒤에야** 영역을 보여 주므로, 창 안에서 글자를 고르거나 파일을 끌어도
  아무 일도 일어나지 않습니다
- Shift를 놓으면 영역이 사라지고 끌기는 평소대로 이어집니다

## 문제 해결

- **영역이 나타나지 않음** — 손쉬운 사용 권한을 확인하세요. 권한이 없으면 메뉴에 ⚠️ 항목이
  보입니다
- **다시 빌드한 뒤로 안 됨** — 위의 ‘다시 빌드할 때 주의’를 보세요
- **어떤 앱만 들어맞지 않음** — 그 앱이 크기 변경을 거부하는 것입니다. 최소 창 크기가 있는
  앱(일부 Electron 앱 포함)은 영역보다 커질 수 있습니다
