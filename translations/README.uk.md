Програма для macOS, що розкладає вікна і не робить нічого, крім поділу екрана.

*Waridake* (割り竹) означає «розколотий бамбук»: один чистий надріз, і все.

**Що вона робить:**

1. Ви задаєте зони для кожного монітора
2. Утримуйте **Shift під час перетягування вікна** — з’являться зони
3. Відпустіть над зоною, і вікно стане в неї

Жодних сіток гарячих клавіш, жодної історії вікон, жодних передплат. Живе в рядку меню.

> Основний — англійський [README.md](../README.md). Якщо цей переклад відстає, чинним є він.

## Встановлення

Потрібні інструменти командного рядка Xcode (`xcode-select --install`).

```bash
git clone https://github.com/omikuji/waridake.git
cd waridake
make install   # → /Applications/Waridake.app
```

Під час першого запуску macOS попросить дозвіл на Універсальний доступ. Увімкніть Waridake
в **Параметрах системи → Конфіденційність і безпека → Універсальний доступ**. Достатньо
зробити це при запущеній програмі: вона помітить за секунду, перезапуск не потрібен.

Щоб запускалася при вході: Параметри системи → Загальні → Об’єкти входу.

### Про перезбирання

Типово підпис ad-hoc, тож **він змінюється при кожному збиранні, і macOS тихо забирає
дозвіл** — прапорець лишається, але нічого не працює. Приберіть Waridake зі списку й додайте
знову або розв’яжіть це остаточно: створіть самопідписаний сертифікат для підписування коду
(Доступ до ключів → Асистент сертифікації → Створити сертифікат, тип: підписування коду) і
збирайте з ним:

```bash
make install SIGN_IDENTITY="Waridake Dev"
```

## Користування

Усе — під піктограмою в рядку меню.

| Пункт меню | Що робить |
| --- | --- |
| **Упорядкувати відкриті вікна** | Ставить кожне відкрите вікно в найближчу зону. Щоб прибрати, коли вікна роз’їхалися |
| **Редагувати розкладку…** | Візуальний редактор, описаний нижче |
| **Розкладки…** | Розкладки за моніторами з датою останнього використання та історія змін |
| **Редагувати як JSON…** | Файл налаштувань у простому вікні редагування |
| **Перезавантажити розкладку** | Перечитує файл після правки деінде |

Розкладки зберігаються **окремо для кожного монітора**, бо екрани різняться формою та
розміром, і один поділ ніколи не пасує всім. Монітори розпізнаються за UUID, тож налаштування
переживають від’єднання та перезавантаження.

### Візуальний редактор

**Редагувати розкладку…** відкриває редактор одразу на всіх під’єднаних моніторах. Формуйте
кожен окремо; натиснути «Зберегти» на будь-якому з них означає зберегти всі. Розміри показано
у відсотках, тож читати частки не доводиться.

| Дія | Що робить |
| --- | --- |
| **Правий клік по зоні** | Поділити на 2 чи 3, розподілити порівну, відцентрувати |
| **Кнопка «Об’єднати» на межі** | Зводить ці дві зони в одну. З’являється там, де вони дають прямокутник |
| Перетягнути межу | Пересуває її. Зони обабіч тягнуться слідом, тож дір не лишається |
| Перетягнути межу **з ⌥** | Пересуває й дзеркальну межу, симетрично центру екрана — щоб рівномірно розширити середню зону |
| Подвійний клік по зоні | Розрізає її в цьому місці вздовж довшої сторони (⌥ змінює напрям) |
| `V` `H` `⌫` `⌘Z` `R` | Поділити, поділити навпаки, об’єднати із сусідньою, скасувати, скинути |
| `return` / `esc` | Зберегти й закрити / відкинути |

«Розподілити цей стовпець рівномірно» вирівнює зони, складені одна над одною в тому самому
стовпці (скажімо, чотири вздовж лівого краю); для рядка вирівнюються ширини. Зони такого ж
розміру в іншому місці екрана лишаються недоторканими.

«Відцентрувати на екрані» зсуває зону так, щоб вона стояла симетрично щодо середньої лінії, не
змінюючи розміру. Зона, притиснута до краю екрана, так рухатися не може, і пункт меню лишається
неактивним.

Межі прилипають до країв інших зон і до 1/4, 1/3, 1/2, 2/3 та 3/4. Регулятор **Проміжок** унизу
задає відстань між зонами; виберіть «Немає», і вікна стоятимуть впритул.

### Розкладки та історія

**Розкладки…** перелічує кожен монітор: чи під’єднаний, що в ньому і коли його використовували
востаннє. Налаштування монітора, якого у вас уже немає, одразу впадають в око — і їх можна
видалити.

Кожне збереження лишає попередній стан у `~/.config/waridake/history/`, останні 10 версій.
Будь-яку можна відновити зі списку, а стан перед відновленням теж архівується, тож нічого не
губиться.

## Налаштування

Файл — `~/.config/waridake/layout.json`, створюється при першому запуску. Це звичайний файл:
вбудований редактор — це зручність, а не вимога.

Кожна зона записується як **частка від 0 до 1** робочої області екрана (того, що лишають рядок
меню й Dock). `x`/`y` відлічуються від лівого верхнього кута, `w`/`h` — ширина й висота, `gap` —
проміжок між зонами в пунктах.

Типово — два однакові стовпці:

```json
{
  "gap": 8,
  "zones": [
    { "x": 0,   "y": 0, "w": 0.5, "h": 1 },
    { "x": 0.5, "y": 0, "w": 0.5, "h": 1 }
  ]
}
```

Зони можуть перекриватися; перемагає перша, що містить вказівник.

### Розкладки за моніторами

Монітори йдуть у `displays`, ключ — UUID монітора. Візуальний редактор пише це за вас.
Монітори без запису беруть `gap` / `zones` верхнього рівня. `name` і `usedAt` — службові
позначки, їх пише лише програма.

```json
{
  "gap": 8,
  "zones": [
    { "x": 0,   "y": 0, "w": 0.5, "h": 1 },
    { "x": 0.5, "y": 0, "w": 0.5, "h": 1 }
  ],
  "displays": {
    "37D8832A-2D66-02CA-B9F7-8F30A301B230": {
      "name": "Studio Display",
      "usedAt": "2026-08-13T12:25:00Z",
      "gap": 0,
      "zones": [
        { "x": 0,    "y": 0, "w": 0.25, "h": 1 },
        { "x": 0.25, "y": 0, "w": 0.5,  "h": 1 },
        { "x": 0.75, "y": 0, "w": 0.25, "h": 1 }
      ]
    }
  }
}
```

Файли без `displays` так само читаються й діють усюди.

## Мови

26 мов, обираються автоматично за мовними параметрами macOS — налаштовувати нічого.

Більшість перекладів зроблено не носіями, тож виправлення — найбажаніший різновид pull request.
Додати мову означає скопіювати `Resources/en.lproj/Localizable.strings` у
`Resources/<мова>.lproj/`, перекласти праву частину кожного рядка й перезібрати. Неперекладене
повертається до англійської.

## Як це влаштовано

- Глобальний монітор подій стежить за перетягуванням лівою кнопкою (саме через це потрібен
  Універсальний доступ)
- При натисканні вікно під вказівником знаходиться через Accessibility API
- Зони з’являються лише після того, як **зрушило саме вікно**: виділення тексту чи перетягування
  файлу всередині вікна нічого не запускає
- Відпустили Shift — зони зникають, а перетягування триває як звичайно

## Усунення проблем

- **Зони не з’являються** — перевірте дозвіл; поки його немає, у меню видно пункт із ⚠️
- **Перестало працювати після перезбирання** — див. «Про перезбирання»
- **Одна програма не стає в зону** — вона відмовляється змінювати розмір. Програми з мінімальним
  розміром вікна, зокрема деякі на Electron, лишаються більшими за зону
